# HelloCucumber

A simple BDD project using JavaScript, Node.js, and Cucumber.js to test whether today is Friday.

## Technologies

- Node.js
- Cucumber.js
- Gherkin

## Installation

bash

```
npm install
```

## Run Tests

bash

```
npm test
```

## Test Scenarios

- Friday → `TGIF`
- Sunday → `Nope`
- Any other day → `Nope`
